# 3(a) Rail Fence Cipher

## Aim

To implement the Rail Fence Cipher.

## Theory

Rail Fence Cipher is a transposition cipher that encrypts data by writing the plaintext in a zigzag pattern across multiple rows. The ciphertext is obtained by reading the characters row by row.

## Algorithm

1. Read the plaintext.
2. Read the depth (number of rails).
3. Arrange the characters in a zigzag pattern.
4. Read each row to generate the ciphertext.
5. Display the encrypted text.

## Time Complexity

O(n)

## Space Complexity

O(n)

## How to Compile

```bash
javac RailFenceCipher.java
```

## How to Run

```bash
java RailFenceCipher
```

## Sample Output

```text
Enter Plain Text : meet me after the toga party
Enter Depth : 2

Encrypted Text : MEMATRHTGPRYETEFETEOAAT
```

# 3(b) Message Rectangle Technique

## Aim

To implement the Message Rectangle Technique for Transposition Cipher.

## Theory

The Message Rectangle Technique is a transposition cipher that places the plaintext into a rectangular matrix row by row. The ciphertext is generated by reading the columns in a specified order.

## Algorithm

1. Read the plaintext.
2. Create a rectangular matrix.
3. Fill the matrix row by row.
4. Read the matrix column by column.
5. Display the encrypted text.

## Time Complexity

O(n)

## Space Complexity

O(n)

## How to Compile

```bash
javac MessageRectangleCipher.java
```

## How to Run

```bash
java MessageRectangleCipher
```

## Sample Output

```text
Enter Plain Text : MEET TOMORROW

Encrypted Text : MTREOREMOTOW
```

## Conclusion

The Rail Fence Cipher and Message Rectangle Technique were implemented successfully. Both techniques rearrange the characters of the plaintext to produce ciphertext and help understand the basic concept of transposition ciphers.
